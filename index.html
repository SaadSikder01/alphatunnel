Step 2: Start your tunnel

Run your local server (e.g., python3 -m http.server 8000) then run this command:

alphatunnel release 8000

It will ask for your Username, Password, and the Token above.

Step 1: First time? Install the CLI

🐧 Linux / Termux
curl -L -o alphatunnel https://github.com/SaadSikder01/alphatunnel-cli/releases/latest/download/alphatunnel-linux-amd64 && chmod +x alphatunnel && sudo mv alphatunnel /usr/local/bin/
🪟 Windows (PowerShell)
$url = "https://github.com/.../alphatunnel-windows-amd64.exe"; ...

⚠️ Termux Users: If you get a "relay unreachable" (DNS) error, run your tunnel using proot:

proot -b $PREFIX/etc/resolv.conf:/etc/resolv.conf alphatunnel release 8000

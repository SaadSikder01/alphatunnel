1 Install the CLI

🐧 Linux (Ubuntu / Debian) 
curl -L -o alphatunnel https://github.com/SaadSikder01/alphatunnel-cli/releases/latest/download/alphatunnel-linux-amd64 && chmod +x alphatunnel && sudo mv alphatunnel /usr/local/bin/
📱 Android (Termux) 
pkg install proot -y && curl -L -o $PREFIX/bin/alphatunnel-bin https://github.com/SaadSikder01/alphatunnel-cli/releases/latest/download/alphatunnel-linux-arm64 && chmod +x $PREFIX/bin/alphatunnel-bin && echo -e '#!/data/data/com.termux/files/usr/bin/bash\nproot -b $PREFIX/etc/resolv.conf:/etc/resolv.conf $PREFIX/bin/alphatunnel-bin "$@"' > $PREFIX/bin/alphatunnel && chmod +x $PREFIX/bin/alphatunnel

✓ This command automatically sets up the DNS fix. You can just run alphatunnel release 8000 afterwards.

🍎 macOS (Apple Silicon) 
curl -L -o alphatunnel https://github.com/SaadSikder01/alphatunnel-cli/releases/latest/download/alphatunnel-darwin-arm64 && chmod +x alphatunnel && sudo mv alphatunnel /usr/local/bin/ && xattr -d com.apple.quarantine /usr/local/bin/alphatunnel
🪟 Windows (PowerShell) 
$url = "https://github.com/SaadSikder01/alphatunnel-cli/releases/latest/download/alphatunnel-windows-amd64.exe"
$dir = "$env:LOCALAPPDATA\AlphaTunnel"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
Invoke-WebRequest -Uri $url -OutFile "$dir\alphatunnel.exe" -UseBasicParsing
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*$dir*") { [Environment]::SetEnvironmentVariable("Path", "$userPath;$dir", "User") }
Write-Host "Installed! Please restart your terminal."

#include <AlphaTunnel.h>

void setup() {
  Serial.begin(115200);
  AlphaTunnel.begin(WIFI_SSID, WIFI_PASSWORD,
                    ALPHA_USERNAME, ALPHA_PASSWORD, ALPHA_TOKEN);
  AlphaTunnel.startLocalServer(80);
}

void loop() {
  AlphaTunnel.loop();
}

Protocol Overview

AlphaTunnel uses a persistent WebSocket to a relay server. All traffic is encrypted via WSS. Authentication is a 3-part handshake:

1. Client → Relay: {username, token, "auth-request"}
2. Relay → Client: {ok: true, public_url}
3. Relay ↔ Client: bidirectional HTTP/WS frames
